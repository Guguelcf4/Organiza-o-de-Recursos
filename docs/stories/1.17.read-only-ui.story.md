## Story
**Como** usuário autenticado, **quero** consultar na interface web informações permitidas ao meu perfil, **para** observar disponibilidade e estado operacional sem executar decisões pela UI.

## Fontes e dependências
- FR-01, FR-03, FR-04, FR-14; NFR-01, NFR-04, NFR-05; PRD §§4–7; Arquitetura ADR-006/007; Constituição Art. I.
- Produto: UI read-only é **obrigatória no MVP**; isso não altera sua limitação arquitetural.
- Dependências: 1.2–1.16. Toda jornada operacional deve estar funcional pela CLI antes da entrega desta UI.
- Critérios legados: parte observacional de AC-31 e AC-32.

## Escopo
UI Next.js somente de consulta autorizada: pesquisa/disponibilidade, status e histórico próprio do Solicitante, informações de recursos/pedidos atribuídos ao Responsável e visão administrativa de leitura quando autorizada. A interface não pode reservar, editar, cancelar, aprovar/rejeitar, administrar nem tomar decisões. Não torna a UI necessária à operação.

## Critérios de aceite
1. UI read-only está disponível como entrega obrigatória do MVP e apresenta consultas correspondentes aos fluxos já operacionais na CLI.
2. Cada perfil visualiza somente dados permitidos; consultas por URL/ID não ampliam acesso e erros não revelam informação restrita.
3. UI não oferece controles, rotas ou chamadas que criem, alterem ou cancelem reservas, decidam aprovações, movimentem materiais ou administrem cadastros/bloqueios.
4. Verificação de rede/servidor confirma que chamadas da UI são somente de leitura; a CLI continua capaz de executar as operações sem a UI.
5. Estados de carregamento, vazio e erro comunicam a condição observável sem expor dados restritos, em alinhamento com NFR-04.
6. Comportamento responsivo é verificado nos dispositivos/plataformas definidos para o produto; não inventar dimensões-alvo, critérios de acessibilidade ou métricas enquanto NFR-04 os mantém “a definir”.

## Definition of Done
- Testes de acesso por persona, acesso direto a identificador e ausência de mutações/decisões pela UI.
- Revisão funcional confirma CLI operacional antes da UI.
- UI e fluxos são descritos conforme comportamento efetivamente disponibilizado, para FR-14/NFR-05.
